# Manual knowledge schema

This is a hybrid operating manual: SKILL.md controls the main line; queries retrieve minimum operational knowledge; topics explain invocation and state boundaries. Read this page, index.md and recent log.md at the first knowledge-dependent node. Then load only the route needed now and return to its named node. Evaluation fixtures stay outside the runtime Skill.

Runtime topic rules are synthesized from the supported engine and verified operations. Live help, tool schemas and catalogs provide version-specific syntax. Source classes: W = traceable upstream/design source; U = confirmed product requirement; E = execution evidence; A = provisional inference. source-manifest.md is for maintainers. Coverage is partial: the manual covers the operating contract, not every engine command or artistic workflow.
